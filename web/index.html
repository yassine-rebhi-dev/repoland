How it works

  1. Install the skill with npx repoland skill. It teaches your agent to read the README, manifests, compose files and entry points, and to include only parts that really exist.
  2. Your agent writes repoland.json: 5 to 16 parts, each with a kind (service, database, queue…), and the flows between them.
  3. repoland lays it out and draws it. Layers follow the data flow, pipes route around buildings, busy hubs stand taller. Same input, same picture, every time.

Using Codex, Cursor or another agent? Run npx repoland skill --print and paste the instructions.
